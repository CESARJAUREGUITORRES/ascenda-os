# Phase 3 private source boundary

The owner workbook used to normalize 2026 product sales contains client-identifying fields and remains outside GitHub.

Repository artifacts may contain only:

- sale row IDs already present in ASCENDA;
- product descriptions/aliases when needed for contracts;
- canonical product names;
- quantities;
- promo/pack flags;
- non-PII integration notes.

Do not commit client names, phones, DNI, email or other clinical/client identifiers from the workbook.
